# Security Policy

## Supported Versions & Official Releases

| Version / Branch | Supported | Notes |
| :--- | :--- | :--- |
| `main` (Latest `vX.Y.Z` Release) | Yes | Actively maintained official release stream |
| Forks, Mirrors, and Older Tags | No | Unverified and unsupported |

Official Android APK packages are distributed exclusively from the primary `DontKwo/AutoSpanish` repository on GitHub (`main` branch and official [Releases](https://github.com/DontKwo/AutoSpanish/releases/latest)).

- **Fork Safety Warning**: Do **not** download or install APKs from forked repositories or third-party mirrors unless you have inspected the source code yourself and confirmed they contain no malware. Only official `main` releases are maintained by the author, and I make no promises.
- **Android Security Prompts**: Because `AutoSpanish` is published directly outside Google Play, Android Play Protect and device package installers will likely warn that the APK is unrecognized or potentially unsafe. Review the [Android APK Installation Guide](docs/APK_INSTALLATION.md) and bypass prompts strictly at your own discretion.

## Reporting a Vulnerability

If you discover a security issue in `DontKwo/AutoSpanish`:

1. **Do not** disclose exploit details in a public GitHub Issue.
2. Open a [Private Vulnerability Report](https://github.com/DontKwo/AutoSpanish/security/advisories/new) on GitHub (or contact `@DontKwo` directly via GitHub).
3. Include reproduction steps, Android version details, and any suggested fix.
